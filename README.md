# Caminho da Autonomia

Uma jornada estruturada de transformação baseada no Ayurveda, na investigação racional e na sabedoria milenar da tradição hindu.

## 📋 Sobre

Página de vendas do programa educacional online **Caminho da Autonomia**. Apresenta os quatro módulos (Artha, Kāma, Dharma e Mokṣa) e oferece inscrição com acesso imediato às aulas gravadas.

### Características

- Design elegante e responsivo (Cormorant Garamond + Cardo)
- Paleta de cores: pergaminho, dourado, vermelho e marrom
- 8 seções de conteúdo + Hero + FAQ
- 100% HTML/CSS (sem dependências externas)
- Otimizado para conversão

## 🚀 Deploy

### GitHub

1. Crie um repositório em https://github.com/new
2. Nome: `caminho-da-autonomia`
3. Deixe **Public**
4. Clique em **Create repository**
5. Na tela seguinte, clique em **uploading an existing file**
6. Arraste/selecione todos os arquivos desta pasta:
   - `index.html`
   - `vercel.json`
   - `.gitignore`
   - `README.md`
7. Clique em **Commit changes**

### Vercel

1. Acesse https://vercel.com/new
2. Selecione **Import Git Repository**
3. Paste a URL do seu repositório GitHub: `https://github.com/[seu-usuario]/caminho-da-autonomia`
4. Clique em **Import**
5. Deixe as configurações padrão
6. Clique em **Deploy**

Seu site estará no ar em segundos! 🎉

URL será algo como: `caminho-da-autonomia.vercel.app`

## 📝 Antes de Publicar

**Importante:** Preencha os seguintes placeholders no `index.html`:

1. **Link do checkout** (3 ocorrências):
   - Procure por `COLOQUE_SEU_LINK_AQUI`
   - Substitua pela URL do seu checkout (Hotmart, Kiwify, etc.)

2. **Depoimentos** (na seção "Testimonials"):
   - Substitua `[Depoimento do aluno...]` por depoimentos reais
   - Atualize `[Nome do aluno]` e `[Perfil · Cidade]`

3. **FAQ** (última pergunta sobre tempo de acesso):
   - Substitua o texto entre colchetes pela política de acesso do seu programa

## 🎨 Customização

O site usa variáveis CSS que podem ser editadas no `<style>`:

```css
:root {
  --saffron: #C0231F;        /* Vermelho principal */
  --gold: #C9A656;           /* Dourado */
  --parchment: #F0E6D2;      /* Fundo claro */
  --maroon-deep: #190404;    /* Fundo escuro */
  /* ... mais cores ... */
}
```

Mudar uma cor aqui afeta o site inteiro.
